# OldPanorama for Windows / LeviLauncher

A native Windows x64 mod intended to keep Minecraft's menu panorama moving when
**Screen Animations** is off, without enabling menu transition animations.

Panorama-only Windows port of the behavior in
[CrackedMatter/mcpelauncher-old-screen-animations](https://github.com/CrackedMatter/mcpelauncher-old-screen-animations).
This does not include the upstream splash-text hook or change rotation direction.

## Status and compatibility

**Experimental: build and native patch tests pass; in-game behavior is unverified.**

- Windows x64, LeviLauncher `preload-native`.
- Minecraft **1.26.0.02**, restricted to this executable SHA-256:
  `3c4e8766700a8f13f6f00fbb06f8a10460b1b99a7bf2c50c3f69a844a31a3c69`.

The manifest has no Minecraft or LeviLauncher version allowlist. The mod's
`version: 0.1.0` identifies its release; it is not a supported-game-version limit.
Removing manifest restrictions does not make the native code universal: the DLL
currently patches only the exact executable identified above. Other builds load
but are rejected by the runtime guard without modifying game memory. Compatibility
with a future loader API cannot be guaranteed.

Different executable hashes and unexpected instructions are rejected.
Only two bytes in process memory are changed. The game executable on disk is untouched.

## Build and test

Install [Zig 0.13.0](https://ziglang.org/download/0.13.0/) for Windows x64, then run:

```powershell
.\build.ps1 -Zig 'C:\path\to\zig.exe'
```

If Zig is on PATH, run `.\build.ps1`.
The script builds the DLL, runs native patch tests, tests DLL loading and rejection
of an unsupported host, and creates `dist/OldPanorama-Windows-0.1.0.zip`.
No Minecraft installation or assets are needed to build.
The GitHub Actions workflow also builds and uploads this ZIP as an artifact.

## Install

1. Close Minecraft.
2. Copy the built `dist/OldPanorama` folder into your instance's `mods` folder.
3. Launch through LeviLauncher with the mod enabled and Screen Animations off.
4. Check whether the panorama moves.

`mods/OldPanorama/OldPanorama.log` reports `APPLIED` or `NOT APPLIED`.
APPLIED confirms the memory patch, not a completed visual test.
Disable the mod in LeviLauncher and restart to undo it. Do not hot-unload it.
